Overdrive Asset Production · Lesson 8

Practical restyling of a simple prop

2026-08-08 · Mission: MISSION.md · ~45 min

The question this lesson answers

How can the visual identity of an asset change while its geometry, hierarchy, and prefab structure remain unchanged?

Restyling changes the surface treatment. It does not silently remodel the object.

This lesson moves away from vehicles and uses a small environment asset: prop_wall_A. A prop is deliberately smaller than a car, so one visual decision can be isolated, compared, and undone without mixing it with vehicle proportions, UV problems, animation, or cockpit materials.

1. The verified prop

The source prefab is:

Assets/Prototype/RaceFeel/Prefabs/prop_wall_A.prefab

It contains two visible mesh branches:

BranchRendererMaterialRole
prop_wall_ARoot MeshRendererGARAGES.matMain wall structure
wall_fence_001Child MeshRendererFENCE.matFence element

This is useful because the prop has more than one material route but remains small enough to understand completely. The root and the child share the prefab hierarchy, but they do not share the same material asset.

2. What restyling is allowed to change

LayerChange in this lesson?
Mesh and silhouetteNo
Hierarchy and child objectsNo
UV layoutNo
Material referenceYes, through an isolated copy
Base Color or Base MapYes, one controlled variable
Shader familyOnly if the experiment explicitly tests it
LightingNo; keep the baseline fixed

The constraint is intentional. If the wall changes shape, material, lighting, and camera at the same time, you cannot know what caused the visual difference.

3. Baseline before editing

  1. Open or import a copy of prop_wall_A.prefab in the lesson Unity project.
  2. Place one original instance in the scene.
  3. Frame the object from the same camera view that will be used after the change.
  4. Capture a baseline image.
  5. Record the root material and the fence material separately.

The baseline must answer:

What is the original geometry?
What is the original material route?
Which parts are controlled by GARAGES.mat?
Which parts are controlled by FENCE.mat?
Which camera and light settings are fixed?

4. Make an isolated material copy

Do not edit GARAGES.mat directly. The original material may be used by other walls or scene instances.

  1. Select GARAGES.mat in the Project window.
  2. Duplicate it.
  3. Rename the copy to GARAGES_Lesson8.mat.
  4. Keep FENCE.mat unchanged for the first experiment.

The intended reference graph becomes:

Original wall instance
  prop_wall_A → GARAGES.mat
  wall_fence_001 → FENCE.mat

Restyled wall instance
  prop_wall_A → GARAGES_Lesson8.mat
  wall_fence_001 → FENCE.mat

Only the root wall material is isolated. The fence remains a control condition.

5. Perform one surface change

Choose one change. Do not combine them in the first pass.

  • change the Base Color to a controlled Overdrive color;
  • replace the Base Map with a prepared painted texture;
  • reduce Smoothness to make the wall less plastic;
  • switch from URP/Lit to Simple Lit as a shader experiment.

The strongest first experiment is usually Base Color or Smoothness because the result is easy to see and does not introduce a new UV question.

Keep these fixed:

  • camera position;
  • camera angle;
  • light direction and intensity;
  • object position and scale;
  • mesh and child hierarchy;
  • the fence material.

6. Assign the copy to one instance

Duplicate the original wall instance in the scene. Assign GARAGES_Lesson8.mat only to the root MeshRenderer of the duplicate.

Do not edit the prefab asset in Prefab Mode for this experiment. A scene-instance assignment makes the scope visible:

Original instance → original material
Duplicate instance → copied material
Same mesh → same hierarchy → different surface result

If both walls change, the material is still shared. If only the duplicate changes, the material route is isolated correctly.

7. Read the visual result

Compare the baseline and the restyled instance using the same camera.

QuestionWhat to inspect
Did the silhouette change?If yes, something beyond material editing changed.
Did the fence change?If yes, the wrong material was edited or shared.
Did the wall become more Overdrive-like?Judge color, surface response, and graphic clarity.
Did the scene lighting change?If yes, the comparison is invalid.
Did the original instance change?If yes, the material copy was not isolated.

8. What this teaches about the art bible

The art bible does not require every asset to be remodeled from scratch. It requires the visible result to belong to the same visual world.

A structurally acceptable prop can move closer to that world through:

  • controlled palette;
  • painted rather than photoreal surface information;
  • reduced unwanted gloss;
  • clear material separation;
  • consistent lighting and presentation.

The mesh is not automatically “Overdrive” or “not Overdrive.” Its surface treatment and presentation are part of the evaluation.

Controlled exercise

  1. Import or copy prop_wall_A.prefab into the lesson Unity project.
  2. Place two instances side by side.
  3. Capture the original instance as the baseline.
  4. Duplicate GARAGES.mat as GARAGES_Lesson8.mat.
  5. Change exactly one material property.
  6. Assign the copy only to the second instance's root MeshRenderer.
  7. Capture the same camera view.
  8. Confirm that the fence and the original wall remain unchanged.
  9. Record whether the result is a useful visual improvement or only a different color.
Expected reasoning

The successful result is not “the wall changed color.” It is: the mesh stayed identical, the fence stayed under its original material, the second wall used an isolated material copy, and one controlled surface change produced a measurable visual difference.

Decision rule

choose a simple prop
  → capture baseline
  → duplicate the material
  → change one surface variable
  → assign the copy to one instance
  → compare under identical presentation
  → classify improvement, neutral change, or regression
