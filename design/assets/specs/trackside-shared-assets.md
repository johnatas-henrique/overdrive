# Asset Spec — Trackside Shared Assets

> **Source:** art-bible.md Sections 5 (Environment Art) + 8 (Asset Standards)
> **Category:** Shared — used across all 4 MVP tracks, no per-track variation beyond material/color tint
> **Status:** Draft
> **Date:** 2026-07-28
> **Placeholder Strategy:** Blockout stage uses colored Primitives (Cube/Cylinder) at target size

---

## 1. Concrete Barrier

**Purpose:** Track-edge collision barrier. Generated procedurally from racing spline edge. One straight segment authored; spline curvature determines placement.

### Spec

| Field | Value |
|-------|-------|
| Mesh | Single straight segment (4m length × 0.8m height × 0.5m depth) |
| Topology | 8 tris (extruded rectangle with chamfered top edge) |
| LOD0 | 8 tris, single mesh |
| Texture | Flat color — painted concrete gray (#B8B8B8) or white+red for kerb-adjacent sections |
| Material | URP Simple Lit, single color |
| Placement | Edge of asphalt surface, continuous along racing spline. Generated by barrier-generation script. |

### Prompt

```
Low-poly single segment of a concrete racing barrier, painted concrete gray (#B8B8B8),
with an angled chamfer on the top edge. Flat cel-shaded style, minimal geometry
(4 meters long, 0.8 meters tall, 0.5 meters thick). Clean bold outlines.
Part of a 1991 formula 1 circuit, painted texture no PBR. Isometric render on white background.
```

### MVP Blockout
- **Asset:** Primitive Cube (4 × 0.8 × 0.5) with gray material
- **Code:** Barrier-generation script reads spline edge, extrudes mesh along racing spline

## 2. Tire Barrier

**Purpose:** Runoff-area impact barrier. Stacked tires at corner exit zones.

### Spec

| Field | Value |
|-------|-------|
| Mesh | Single tire (torus, low-poly 16 sides) × stack of 3-5 |
| Topology | ~100 tris per stack |
| LOD0 | Single stack (250 tris, one material) |
| Texture | Flat dark gray/black (#2A2A2A) with subtle sidewall detail |
| Placement | At gravel/runoff exit of corners. Placed manually in per-track scene. |
| Count per track | 8-20 stacks depending on corner count |

### Prompt

```
Low-poly stack of racing tires forming a tire barrier, used at the edge of a formula 1 circuit
runoff area. Three tires stacked in a pyramid, dark rubber gray (#2A2A2A),
simple torus shapes with flat cel-shaded finish. Clean outlines, painted texture no PBR.
Part of a 1991 racing circuit aesthetic. Isometric render on white background.
```

### MVP Blockout
- **Asset:** 3 Cylinders stacked, dark gray material

## 3. Grandstand

**Purpose:** Spectator seating area. Two variants: small (200 seats, mid-corner) and large (1000+ seats, main straight/pit).

### Spec

| Field | Small Variant | Large Variant |
|-------|---------------|---------------|
| Dimensions | 10m × 8m × 4m (W×D×H) | 30m × 12m × 8m (W×D×H) |
| Topology | ~200 tris | ~600 tris |
| Structure | Metal frame + bench rows, no roof | Stepped concrete tiers, optional roof canopy |
| Material | URP Simple Lit, team-color accent | URP Simple Lit, concrete + team color trim |
| Texture | Flat colored, no PBR | Flat colored, no PBR |
| Seats | Colored per corner (team tint at 20%) | Colored per corner |

### Prompt (Small)

```
Low-poly small grandstand at a 1991 formula 1 circuit, open metal frame structure,
four rows of bench seating in a muted team color, simple stepped profile,
flat cel-shaded painted texture. Clean bold outlines, no photo-realism.
Isometric render on white background. Dimensions roughly 10 meters wide.
```

### Prompt (Large)

```
Low-poly large covered grandstand at a 1991 formula 1 circuit, concrete tiered structure
with a flat roof canopy, stepped seating rows in alternating colors,
clean geometric cel-shaded style, painted textures no PBR.
Spectators represented as colored dots on the seats. Isometric render on white background.
Dimensions roughly 30 meters wide.
```

### MVP Blockout
- **Asset:** Box (10 × 8 × 4) with stepped top, light gray material

## 4. Tree

**Purpose:** Ambient vegetation. 3 variants — round canopy (pine/spruce), round broadleaf (oak/maple), tall thin (palm/cypress for Monaco).

### Spec

| Field | Round Conifer | Broadleaf | Tall (Monaco) |
|-------|--------------|-----------|---------------|
| Mesh | Cone + cylinder trunk | Sphere cluster + cylinder | Cylinder + small top cluster |
| Topology | ~60 tris | ~120 tris | ~50 tris |
| Billboard | LOD1+ uses crossed-quad billboard | Same | Same |
| Material | URP Simple Lit, single color | URP Simple Lit, 2 colors | URP Simple Lit |
| Green tint | #4A7C3F (deep green) | #5B8C4A (warm green) | #6B9C5A (light green) |
| Trunk | #6B4226 (brown) | #6B4226 | #8B6B4A (light brown) |

### Prompt

```
Low-poly stylized tree for a 1991 formula 1 circuit trackside environment,
cel-shaded anime aesthetic. Round clustered canopy in warm green (#5B8C4A),
simple cylindrical trunk in brown (#6B4226). Clean bold outlines, painted texture,
no photo-realism, no leaf detail. Flat shaded, minimal geometry.
Isometric render on white background.
```

### MVP Blockout
- **Asset:** Two crossed quads (billboard) with green on top half, brown on bottom. Unified material.

## 5. Distance Board

**Purpose:** Braking distance indicator before corners. 100m/50m/board panels.

### Spec

| Field | Value |
|-------|-------|
| Mesh | Flat rectangle on a pole (two quads, pole is cylinder) |
| Topology | ~12 tris |
| Text | "100" or "50" in white on red/green background |
| Size | 2m × 1.5m panel, 2m pole |
| Placement | Procedural — placed at 100m and 50m before each corner's curvature peak |
| Material | URP Simple Lit, emissive white text on red (#C62828) or green |

### Prompt

```
Low-poly distance marker board at a 1991 formula 1 circuit, a white rectangular sign
with the number "100" in large bold digits on a red background (#C62828),
mounted on a short metal pole. Flat cel-shaded painted style, clean bold outlines,
no photo-realism. Isometric render on white background.
```

### MVP Blockout
- **Asset:** Quad with colored material + text (or just colored quad with "100"/"50")

| Placement | At straights and corner exits. Placed manually, 6-12 per track. |

### Prompt

```
Low-poly trackside advertising billboard at a 1991 formula 1 circuit,
a large rectangular panel (6 meters wide, 3 meters tall) with geometric color blocks
in racing team colors — bold red (#E03C31), white (#FFF8F0), and blue sections.
Thin metal tube border. Flat cel-shaded painted texture, clean outlines,
no photo-realism. Isometric render on white background.
```
