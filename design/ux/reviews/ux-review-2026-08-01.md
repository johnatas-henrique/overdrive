## Findings

### BLOCKING

**B1 — Screen reader beyond Standard tier (10 specs)**
- 10 specs promised active screen reader support ("Screen reader announces...") in Accessibility sections and Acceptance Criteria
- `accessibility-requirements.md:149`: "Screen reader support ❌ Out of scope — Not targeted at Standard tier"
- **Decision (user):** rewrite as "Accessible labels" — semantic names for future assistive tech expansion, no active support claimed
- **Applied:** all 10 Accessibility sections + 6 ACs rewritten. Zero "Screen reader" references remain.

**B2 — race-hud.md out of sync with ADR-0014 (7 vs 8 elements)**
- Spec said "7 elements" (Position/Lap merged, "Race Time") in 5 places (philosophy, must-show, camera behavior ×2, state-based visibility) while its own detailed element section had 8, and the ADR-0014 (Accepted 2026-08-01) defines 8 MVP elements + Ghost 9th
- **Applied:** inventory renumbered to 8 MVP (Speed, Position, Lap, Fuel, Tire, Lap Time, Rival, Map) + Ghost 9th (Alpha); all visibility tables and philosophy updated to 8

**B3 — "Grid Display" residuals (3 files)**
- interaction-patterns:17, race-hud:355, ui-menu:14 still used the pre-rename alias
- Canonical name per memory #1620: "Qualifying Results"
- **Applied:** all 3 corrected

### MAJOR

**M1 — race-hud default contradiction (:83-84)**
- "Why OFF is default" contradicted the visibility table ("ON (default)")
- Memory #1241 confirms ON default
- **Applied:** rewritten to "Why ON is default" with the immersion trade-off explained

**M2 — CameraToggle binding wrong (interaction-patterns:102)**
- Spec said "Right stick click / C"; input-system.md:79/93 defines **C / gamepad North-Y-Triangle**
- **Applied:** corrected to "C / gamepad North-Y-Triangle (per input-system.md default bindings)"

**M3 — Next Race eliminated (results.md:67)**
- Spec claimed "Next Race is equivalent to Continue (return to menu)"
- ui-menu GDD:104/121 + RSM:148 define Next Race as a distinct action: re-race same config → Loading TransitionRequest, no Idle intermediate
- **Decision (user):** keep Next Race in MVP, aligned to GDD/RSM
- **Applied:** Next Race added to results.md (Exit Points, Component Inventory, Interaction Map, Events, ACs, wireframe, notes)
